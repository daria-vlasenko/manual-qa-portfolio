# Техники тест-дизайна

Практика применения техник тест-дизайна и чек-листов веб-тестирования.

## Содержание

- **[shipping-calculator-pairwise.md](shipping-calculator-pairwise.md)** — калькулятор доставки: классы эквивалентности, граничные значения, таблица принятия решений (12 комбинаций), попарное тестирование (сокращение до 6 наборов), 5 тест-кейсов с приоритетами.
- **[registration-form-checklist.md](registration-form-checklist.md)** — чек-лист веб-тестирования поля «Имя» формы регистрации: границы длины, обработка пробелов, не-латинские символы, HTML-инъекции, XSS, SQL-инъекции. По условию задания требовалось найти не менее 50% проверок — найдено 72%.

## Применённые техники

| Техника | Где применена |
|---|---|
| Классы эквивалентности | Вес и расстояние — по 4 класса, валидные и невалидные |
| Граничные значения | По 6 точек на параметр: порог ошибки и порог наценки |
| Таблица принятия решений | 12 строк: 3 типа доставки × 2 уровня веса × 2 уровня расстояния |
| Попарное тестирование | 6 наборов вместо 12 при сохранении покрытия всех пар параметров |
| Чек-лист веб-поля | Позитивные проверки, границы, пробелы, кодировка, безопасность |
