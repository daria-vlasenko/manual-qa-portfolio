# Manual QA & Test Design Portfolio

Артефакты ручного тестирования и тест-дизайна: поиск и оформление дефектов, техники тест-дизайна, чек-листы, тест-документация полного цикла. Автоматизированные проекты — отдельно: [conduit-api-tests](https://github.com/daria-vlasenko/conduit-api-tests) (REST Assured), [java-testing-practice](https://github.com/daria-vlasenko/java-testing-practice) (JUnit 5 + Mockito).

## Содержание

- **[modsen-website-bugs](./modsen-website-bugs)** — 20 дефектов, найденных на реальном сайте modsen-software.com (практика в Modsen, июнь–июль 2026).
- **[testing-basics-practice](./testing-basics-practice)** — 15 тест-кейсов на форму регистрации + 10 багов на учебном магазине AcademyBugs.
- **[test-design-techniques](./test-design-techniques)** — эквивалентное разбиение, граничные значения, таблица принятия решений и попарное тестирование (калькулятор доставки); чек-лист веб-тестирования поля формы (эквивалентность, безопасность, XSS/SQL-инъекции).
- **[agile-sprint-planning](./agile-sprint-planning)** — MVP и планирование первого спринта по Agile/Scrum.
- **[bsuir-coursework-file-converter](./bsuir-coursework-file-converter)** — учебный курсовой проект (БГУИР): полный цикл тест-документации для консольного приложения — от анализа требований до итогового отчёта о тестировании, 7 лабораторных работ.
