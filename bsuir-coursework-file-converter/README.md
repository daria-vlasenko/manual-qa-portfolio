# Курсовой проект БГУИР — «Конвертер кодировок»

Учебный проект по курсу «Разработка и анализ требований к программному обеспечению» (БГУИР, 2025). Объект тестирования — консольное PHP-приложение для автоматического определения и преобразования кодировки текстовых файлов (`converter.phar`). Полный цикл тест-документации от анализа требований до отчёта по результатам тестирования, 7 лабораторных работ.

| Файл | Лабораторная | Содержание |
|---|---|---|
| [01-test-plan.pdf](./01-test-plan.pdf) | №1 | Тест-план проекта: цели, объём тестирования, стратегия, критерии качества, ресурсы, риски |
| [02-requirements-defects-search.pdf](./02-requirements-defects-search.pdf) | №2 | Поиск дефектов в формулировках требований (неоднозначность, проверяемость, атомарность, полнота) |
| [03-requirements-fixed.pdf](./03-requirements-fixed.pdf) | №3 | Исправленная версия требований к проекту после устранения найденных дефектов |
| [04-checklists.pdf](./04-checklists.pdf) | №4 | Чек-листы: дымовое тестирование, тестирование критического пути, расширенное тестирование |
| [05-test-cases.pdf](./05-test-cases.pdf) | №5 | Тест-кейсы на основе чек-листов и требований |
| [06-defect-report.pdf](./06-defect-report.pdf) | №6 | Отчёт о дефектах приложения — 5 дефектов с шагами воспроизведения, серьёзностью и срочностью, скриншотами |
| [07-test-summary-report.pdf](./07-test-summary-report.pdf) | №7 | Итоговый отчёт о результатах тестирования: статистика по 8 дефектам, критерии завершения тестирования, рекомендации |

**Итог тестирования:** выполнено 100% запланированных тест-кейсов, найдено 8 дефектов (1 фатальный, 5 серьёзных, 2 незначительных). Критерии завершения тестирования не достигнуты — дефекты высокой и критической важности блокируют критический путь, релиз до их устранения признан невозможным.
