# Agile Practice — MVP и планирование спринта

Задача: по описанию проекта определить минимальный набор функций (MVP) и задачи на первый двухнедельный спринт.

**Проект:** веб-приложение для загрузки, просмотра и обсуждения видео — пользователи публикуют видео, просматривают материалы, оставляют комментарии, выбирают категории и получают базовые рекомендации по интересам.

**MVP:** регистрация и авторизация, загрузка видео с описанием, просмотр списка и отдельного видео, комментирование, категории и фильтрация по ним, базовые рекомендации по интересам, базовая валидация данных.

**Задачи первого спринта:**
1. Базовая структура проекта и минимальный рабочий сценарий.
2. Регистрация и авторизация пользователей.
3. Загрузка видео (название, описание, категория).
4. Каталог видео с фильтрацией по категориям.
5. Страница отдельного видео с комментариями.
6. Базовая логика рекомендаций по выбранным категориям.
